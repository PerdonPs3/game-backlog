# Platform icons

These eight unmodified SVG files come from Simple Icons 11.15.0:
https://github.com/simple-icons/simple-icons/tree/11.15.0/icons

Included slugs: windows, playstation, xbox, nintendoswitch, nintendo, apple,
linux and steam. The upstream CC0 license is preserved in LICENSE.md.

Icons are served locally and colored through CSS masks. No icon CDN request is
made by the browser. Steam represents an explicitly validated catalog store
link; Windows support alone does not imply Steam availability.
